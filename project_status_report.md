## 2. Project Objectives (What You Have To Do)
The primary goal of this project is to build a comprehensive engine that optimizes digital content for Generative Search Engines (e.g., Perplexity, Google SGE). The key technical objectives include:
*   **GEO Perception Layer:** Development of a scoring system to evaluate content based on AI-native metrics (Structural Clarity, Semantic Richness, and Citation Worthiness).
*   **Action Layer (Optimizer):** Implementation of an LLM-driven engine to rewrite existing content into "Inverted Pyramid" structures and generate new grounded content.
*   **Structured Data Integration:** Automated generation of JSON-LD Schema.org markup (Article, FAQ, How-To) to improve AI indexing.
*   **Live Verification:** Real-time validation of AI citations to ensure content is being referenced accurately by LLM search engines.
